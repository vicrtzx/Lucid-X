# Lucid X v1.0 (iOS)

Lucid X is an ultra-battery-efficient, decluttered, and high-performance mod of Twitter / X for iOS.

## Features
- **Liquid Glass Monochrome Design:** AMOLED true pitch-black background (`#0A0A0D` / `#000000`) designed to turn off OLED pixels on iPhone 17's Super Retina XDR display.
- **Zero Ads & Pure Timelines:** 100% ad-free experience. Promoted tweets, video ads, promoted trends, and suggestion clutter completely removed.
- **Privacy & Anti-Tracking:** Automatically strips tracking parameters (`utm_`, `?s=20&t=...`) from shared links.
- **1-Tap Media Downloader:** Download videos in highest quality (1080p/4K) and audio notes directly to iOS Camera Roll.
- **Storage Optimizer:** Asynchronous background cache cleaner prevents temporary media buildup.
- **Security:** Optional Face ID / Passcode app lock.
- **Localization:** Native Brazilian Portuguese (PT-BR) and English.
